# SNARTY_NOART

A [Rockbox](https://www.rockbox.org/) theme for 320x240 players: a variant of SNARTY without album art.

Upstream SNARTY draws a 114x114 album art box at the left of the While Playing Screen and lock screen. Here it is removed, and the track title, artist, album, file info and peak meter span the full width of the screen instead.

## Installing

Copy the `fonts/`, `icons/`, `themes/` and `wps/` directories into `/.rockbox/` on the player, then select the theme under Settings > Theme Settings > Browse Theme Files.

The theme files are all named `SNARTY_NOART`, so it installs alongside upstream SNARTY without overwriting it. The KodeMono fonts are identical to the ones SNARTY ships and are shared with it.
